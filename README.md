# ProblemasAstronomia 🌌

Un repositorio educativo que contiene una colección de problemas de astronomía con sus soluciones analíticas y numéricas implementadas en Wolfram Language/Jupyter Notebooks.

## 📋 Descripción

Este proyecto reúne problemas clásicos y contemporáneos de astronomía, proporcionando:
- **Soluciones analíticas**: Desarrollo matemático detallado de cada problema
- **Soluciones numéricas**: Implementaciones en Wolfram Language para validar resultados
- **Jupyter Notebooks**: Documentación interactiva con visualizaciones

Ideal para estudiantes de física, astronomía e ingeniería que deseen comprender mejor los fenómenos celestes.

## 📚 Contenido

- Mecánica orbital
- Gravitación
- Movimiento de cuerpos celestes
- Astrofísica observacional

## 🛠 Entorno de desarrollo
- Python 3+
- Wolfram Language 12.3.1+
- Wolfram Player
- Jupyter Notebook o JupyterLab


## 💻 Instalación

1. Clona este repositorio:
   ```bash
   git clone https://github.com/Daniel-534/ProblemasAstronomia.git
   cd ProblemasAstronomia
   ```
3. Abre Jupyter:
   ```bash
   jupyter notebook
   ```

## 📖 Cómo usar

1. Navega a la carpeta del problemset que te interese
2. Lee el problema del `.pdf`y sigue el desarrollo de la solución
3. Abre el notebook `.ipynb` correspondiente
4. Ejecuta las celdas para ver los cálculos y gráficos
